# akhan-dev

Русскоязычное портфолио Артема Хана ([akhandev.ru](https://akhandev.ru)) и восемь демонстрационных сайтов-концептов. Astro 6, статическая сборка, TypeScript в режиме `strictest`, обычный CSS. Базы данных и переменных окружения нет.

Исходный код: https://github.com/akhandevru/akhan-dev

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev      # http://127.0.0.1:4321
npm run build    # astro check + astro build; ошибок, предупреждений и подсказок должно быть 0
npm run preview  # просмотр собранного сайта
```

## Страницы

| Адрес | Что там |
|---|---|
| `/` | Главная: чёрная дыра на первом экране, проекты лентой в 3D, этапы работы, цены, обо мне, контакты |
| `/projects/` | Все работы строками |
| `/development/` | Как работаю: этапы, что входит в разработку, что нужно от клиента, что он получит в конце |
| `/pricing/` | Стоимость: карточки услуг, калькулятор (сайт, бот, админка, доп. страницы с ценой, которая падает с их числом; расчёт переходит в заявку), от чего зависит цена, вопросы про оплату |
| `/about/` | Обо мне: фото, стек, последние работы, ссылка на исходный код этого сайта |
| `/contact/` | Контакты и сборщик первого сообщения (подхватывает расчёт из калькулятора; текст копируется, никуда не отправляется) |
| `/privacy/` | Политика конфиденциальности |
| `/demos/<имя>/` | Демо-сайты, у каждого `noindex` |

## Где менять

- `src/config.ts`: все тексты, контакты, навигация, цены, адрес сайта. Тексты правим здесь, а не в компонентах. Дополнительные блоки страниц разделов лежат в `content.extras`, заголовки и описания страниц в `content.pages`.
- `src/data/projects.ts`: проекты. Порядок в массиве равен порядку на главной (показываются первые шесть, остальные на `/projects/`). Для каждого нужны превью `src/assets/projects/<id>.png` шириной 1440 px и ссылка `demo` на `/demos/<id>/index.html`.
- `src/styles/global.css`: палитра и токены. Тема одна, почти чёрная, акцент белый на тёмном и чёрный на светлом.
- `src/lib/seo.ts`: разметка schema.org. Новую страницу добавлять в `src/pages/sitemap.xml.ts` и давать ей свои `title` и `description` (до 60 и до 160 символов).
- `public/og.jpg`: превью для соцсетей, 1200 на 630. Значки: `favicon.svg`, `favicon-48.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`.

## Демо-сайты

Папки `public/demos/<имя>/` это самостоятельные статические сайты без сборки: `komnata`, `kontur`, `gran`, `list`, `shov`, `umlaut`, `socvetie`, `poltarelki`. Бренды, товары, цены, адреса и отзывы вымышлены, об этом сказано на самих сайтах. Общие `concept.css` и `concept.js` дают плашку «Концепт-сайт» и заглушки контактов. Фото из Unsplash, шрифты с открытыми лицензиями.

Новое демо: папка в `public/demos/`, карточка в `projects.ts`, превью 1440 px, проверка на ширине 390 px без горизонтальной прокрутки.

## Как устроено

- Шапка, меню на весь экран и палитра команд (Ctrl+K) ведут на страницы разделов. На главной раздел подсвечивается по прокрутке, на странице раздела ссылка помечена `aria-current="page"`.
- Фон сайта: свой шейдер на обычном WebGL (`src/scripts/shader-bg.ts`). Поверх него «лава-лампа» из графитовых капель (`src/scripts/ink-bg.ts`): на главной появляется у раздела «Как работаю», на остальных страницах видна сразу.
- Чёрная дыра на первом экране и лента проектов: `src/scripts/scene3d.ts` (three.js, подгружается динамически), шейдер дыры в `hole-shader.ts`. Уменьшенная версия на странице 404: `hole-mini.ts` на голом WebGL.
- Анимации: `src/scripts/motion.ts` (GSAP) и CSS `animation-timeline`. При `prefers-reduced-motion: reduce`, без WebGL или WebGPU и без JavaScript остаётся обычная вёрстка.
- Яндекс Метрика грузится только после согласия посетителя (`CookieBanner.astro`). На `localhost` не загружается.

Подробности и принятые решения: [CLAUDE.md](CLAUDE.md).

## Деплой

Свой сервер через Docker. `Dockerfile` собирает сайт (`node:22-alpine`) и раздаёт его из `caddy:2-alpine`; `Caddyfile` включает сжатие, заголовки безопасности, кеш и автоматический HTTPS. `docker-compose.yml` запускает один сервис `web`, домен задаётся переменной `DOMAIN` (по умолчанию `akhandev.ru`).

```sh
docker build --platform linux/amd64 -t gr1nder05/akhandev:latest .
docker push gr1nder05/akhandev:latest
# на сервере, в папке с docker-compose.yml
docker compose pull && docker compose up -d
```

При смене домена обновить `siteConfig.url` в `src/config.ts` (из него берутся canonical, превью, sitemap и разметка) и перерисовать `public/og.jpg`, если на нём написан адрес.
